# 足し算れんしゅうアプリ 🎯

子供向けの算数学習Webアプリです。簡単な足し算を楽しく学べます。

## 機能

- **ランダム問題生成**: 0〜10の数字を使った足し算の問題がランダムに出題されます
- **即座のフィードバック**: 正解・不正解を分かりやすく表示
- **スコア記録**: 正解数と総問題数を記録
- **子供向けデザイン**: 明るくカラフルで楽しいUI
- **効果音**: 正解時に楽しい音が鳴ります
- **レスポンシブ対応**: スマートフォンでも快適に使えます

## 使い方

1. **ブラウザで開く**
   - `index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップします

2. **問題を解く**
   - 画面に表示された足し算の問題を解きます
   - 例: 「3 + 4 = ?」なら、答えは「7」です

3. **答えを入力**
   - 答えの数字を入力欄に入力します
   - 「こたえる」ボタンをクリックするか、Enterキーを押します

4. **結果を確認**
   - 正解なら「🎉 せいかい！」と表示されます
   - 不正解なら正しい答えが表示されます

5. **次の問題へ**
   - 「つぎのもんだい →」ボタンをクリックして次へ進みます

## 学習内容

### 足し算とは？

足し算は、2つ以上の数を合わせて合計を求める算数の基本操作です：

- 0 + 1 = 1
- 1 + 2 = 3
- 2 + 3 = 5
- 3 + 4 = 7
- 4 + 5 = 9
- 5 + 6 = 11
- 6 + 7 = 13
- 7 + 8 = 15
- 8 + 9 = 17
- 9 + 10 = 19

### なぜ重要？

足し算は算数の基礎として非常に重要です：
- 繰り上がりのある計算の理解につながります
- 暗算能力の向上に役立ちます
- 数の感覚を養います

## Python コード解説：`pr = list(product(range(nw), range(nf)))`

このコードは Python の `itertools.product` を使い、2つの範囲の**直積（デカルト積）**をリストとして作成します。

### 各部分の意味

| コード | 意味 |
|---|---|
| `range(nw)` | 0 から nw-1 までの整数のシーケンス（例: nw=3 → [0, 1, 2]） |
| `range(nf)` | 0 から nf-1 までの整数のシーケンス（例: nf=2 → [0, 1]） |
| `product(range(nw), range(nf))` | 2つのシーケンスの全ての組み合わせ（直積）を生成するイテレータ |
| `list(...)` | イテレータをリストに変換 |
| `pr = ...` | 結果を変数 `pr` に代入 |

### 使用例

```python
from itertools import product

nw = 3
nf = 2
pr = list(product(range(nw), range(nf)))
print(pr)
# 出力: [(0, 0), (0, 1), (1, 0), (1, 1), (2, 0), (2, 1)]
```

- `range(nw)` = [0, 1, 2]
- `range(nf)` = [0, 1]
- `product` はこの2つの全ての組み合わせを作るため、nw × nf = 3 × 2 = **6個のタプル**が得られます。

### 直積とは？

直積（デカルト積）とは、2つの集合のすべての要素の組み合わせを作ることです。  
数学的には `A × B = {(a, b) | a ∈ A, b ∈ B}` と表されます。

例えば格子状のグリッド（nw 列 × nf 行）の全マスの座標を列挙するときなどに活用されます。

### 注意点

`itertools` は Python 標準ライブラリに含まれているため、別途インストールは不要です。  
使用する際はファイルの先頭で以下のようにインポートしてください：

```python
from itertools import product
```
